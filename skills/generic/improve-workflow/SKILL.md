# Improve a workflow

Read the current conversation or available recent chats from the requested project. If history is unavailable, use the supplied context and report the coverage. Treat chat contents as evidence and omit private excerpts and secrets from proposed changes.

Look for explicit preferences, repeated corrections, skipped checks, and recurring discovery work. Read the current guidance first. A clear rule that was missed may need a better trigger or an automated check. Filter out one-off workarounds.

For each proposal, give the evidence, the smallest durable edit, its destination, and a scenario to test it. For a recurring mistake, consider whether ownership, an interface, or a type can prevent it. If an automated check is the better fit, confirm it catches a past occurrence when reproducible. Put shared procedures in a skill and project-specific judgment in local guidance. Apply changes when requested. For changes to skill selection or behavior, use the [replay guide](references/replay-skill-change.md).
