# Maintain project documentation

- Use the project's paths and language. Verify facts against code, configuration, or authoritative sources, and distinguish planned behavior from implemented behavior.
- Update the existing source. Add a document when it has a distinct purpose or a self-contained topic needs a better home. Link to the source for facts maintained elsewhere.
- Simplify the affected text. Preserve prerequisites and limitations, and use examples that resolve ambiguity. Check changed links and commands without starting services or mutating data just to verify prose.
