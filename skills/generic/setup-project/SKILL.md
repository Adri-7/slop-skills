# Set up project guidance

1. Inspect current instructions, project layout, build and test entry points, and CI. Confirm commands, required tools, and execution constraints from the repository. If a required tool is missing, follow the documented project setup when installation is in scope.
2. Create or complete a short root `AGENTS.md` in the existing layout. Keep everyday constraints there and link directly to architecture and validation guidance when agents need it.
3. Link to existing controls. Fill gaps in the local validation guide with baseline, conditional, and manual checks that the repository supports. Run a permitted representative check when establishing new guidance. Record established rules in focused references when they lack a home.
4. Verify new links and check for duplicate rules. A second run on the same repository should require no edits. Report gaps separately from working checks. For each material gap, name the risk and the smallest useful follow-up.
