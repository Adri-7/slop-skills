# In your own words

State the problem as you understand it, the outcome the user wants, and any constraint that materially changes the work. Distinguish what the user said from what you inferred. Mention an unresolved choice only if the answer changes the scope, behavior, or deliverable.

When the request is only to confirm understanding, return the restatement. When it is part of a request to do the work, continue if the restatement leaves no material blocker.
